# コウジ｜サムネイルポートフォリオ

GitHub Pagesで公開するための静的サイトです。`index.html` と `assets/` を同じ階層に置いてください。

## 公開設定

GitHubにこのフォルダ内のファイルをアップロードし、リポジトリの Settings → Pages → Build and deployment で Source を `Deploy from a branch`、Branch を `main`、Folder を `/(root)` に設定して Save します。

公開URLは GitHub の Pages 設定画面に表示されます。変更内容を `main` に反映すると同じURLで更新されます。
